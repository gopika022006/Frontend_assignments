Gopika G S — Beginner Developer Portfolio
===========================================

Files
-----
- index.html: portfolio content and semantic page structure
- style.css: layout, colors, typography, responsive styling

How to run
----------
1. Extract the ZIP file.
2. Keep index.html and style.css in the same folder.
3. Double-click index.html to open it in a browser.
4. To edit the portfolio, open the files in VS Code.

Notes
-----
- Built using HTML and CSS only. No JavaScript is used.
- The content is based on the uploaded resume.
- The Google Fonts import needs an internet connection; the page uses fallback fonts if unavailable.
- Replace the email/phone or any details if you want different public contact information.
- Add GitHub/LinkedIn links when you have the profile URLs; they were not included in the resume, so none were invented.
